# Mowa! Exam Escape

**Syllabus chadavaledu. Escape avvali.**

A tiny student-life endless runner: jump over surprise tests and assignments, slide under lecturer chaos, collect chai boosts, and beat your best distance.

## Play
Open `index.html` in a browser, or deploy the repository to Vercel as a static site.

## Controls
- Space / ↑: jump
- ↓: slide
- Touch: tap game area or use on-screen buttons

No build step, dependencies, or API keys required.

# ANIME RIFT.exe

**Mowa.exe presents:** ANIME RIFT.exe  
*Two worlds. One battlefield. No rules.*

A browser-first 2D arena-fighter prototype built with Phaser 3, TypeScript and Vite.

## Run locally
```bash
npm install
npm run dev
``

## Production build
```bash
npm run build
npm run preview
``

## Current playable milestone
- Main menu and playable arena
- Two original placeholder combatants (Rift Runner and Shinobi Echo)
- Player movement, jump, block, dash, light/heavy attacks
- Energy-building special and ultimate attacks
- Basic opponent AI, health/energy HUD, timer, round result and rematch
- Keyboard and touch controls
- Responsive canvas layout

## Controls
| Action | Keyboard |
|---|---|
| Move | A / D |
| Jump | W |
| Block | S |
| Light | J |
| Heavy | K |
| Special | L |
| Ultimate | U |
| Dash | Shift |

## Notes
This prototype uses original abstract fighter silhouettes and generated-in-code effects, not official anime artwork, music or logos. The One Piece/Naruto crossover was the initial fan-prototype direction; public release with protected characters or assets requires permission. Replace the temporary fighters with original or licensed characters before a public commercial launch.

Online multiplayer, story mode, progression and the expanded roster are not part of this first milestone.
